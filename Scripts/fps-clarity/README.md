# Loopback measurement draft

These experimental probes were used for a local measurement. They do not modify product defaults. They measure JPEG frame arrival, not browser display or phone decoding, and use a synthetic mostly white, animated native window.

Use a disposable worktree. Confirm no other WindowShare host is running, and use an already-authorized signed build. Do not trigger a macOS permission prompt or capture an unrelated window. Build `target.swift` inside a signed `.app` bundle and launch it in the background without activation; select its exact window ID. The target updates a counter at 30 Hz and includes the same 12–16 point test strings as the readability fixture. Run the host with `--window-id` and `--persistent`, redirecting output to a private file (`chmod 600`); the file contains a private share link and must not be shared. Set `WS_HOST_LOG` to that file and `WS_RESULTS_DIR` to a private results directory. `stream.py` records 62 seconds of per-frame elapsed times and JPEG sizes and saves one JPEG; `WS_LABEL` names its output. `interact.py` requires Python `websocket-client`, acquires an Interact lease and measures the long-poll snapshot endpoint for 62 seconds without sending input. Stop the host and fixture when finished.

For test-only quality overrides, run `python3 Scripts/fps-clarity/instrument.py` in the disposable worktree, build a separate signed host and then `python3 Scripts/fps-clarity/instrument.py --restore`. The instrumented executable accepts `WS_MEASURE_FPS`, `WS_MEASURE_SCALE`, `WS_MEASURE_CAP`, and `WS_MEASURE_QUALITY`. The original source remains the production baseline. `clarity.py` starts that binary sequentially using `WS_HOST_BIN`, `WS_WINDOW_ID`, and `WS_RESULTS_DIR`; it assumes ports 8777/8778 are free and creates a private temporary host log containing the share link, removed on normal exit. It collects one snapshot per configuration, not a performance run.

OCR may be run with `tesseract image.jpg output -l eng+chi_sim --psm 6`. Compare output with the target text; OCR is not a substitute for human viewing at the phone's actual displayed size. The raw sampling records exclude multipart headers and TCP/IP overhead.
